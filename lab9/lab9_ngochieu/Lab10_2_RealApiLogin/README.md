# Lab10_2_RealApiLogin

A Flutter project demonstrating integration with a real REST API (DummyJSON) for user authentication.

## How to Run the App
1. Navigate into this project directory:
   ```bash
   cd Lab10_2_RealApiLogin
   ```
2. Run the application:
   ```bash
   flutter run
   ```
